# Archivos Originales

Esta carpeta contiene los archivos de la **versión monolítica original** del proyecto.

## ⚠️ Archivos Deprecados

Estos archivos **NO se utilizan** en la nueva arquitectura separada (Frontend/Backend).

Se mantienen aquí únicamente como:
- 📦 Backup/referencia histórica
- 🔍 Comparación con la nueva estructura
- 🛡️ Seguridad (por si necesitas revertir cambios)

## 📂 Contenido:

- `*.php` - Archivos PHP originales que mezclaban HTML y lógica
- `api/` - Copia de la API original
- `public/` - Carpeta pública original con assets
- `usermodel/` - Modelos originales
- `views/` - Vistas HTML originales
- `resources/` - Recursos (manual PDF)

## ✅ Nueva estructura (usar esta):

- **Backend:** `../backend/`
- **Frontend:** `../frontend/`

## 🗑️ Puedes eliminar esta carpeta

Una vez que confirmes que todo funciona correctamente con la nueva estructura separada, puedes eliminar esta carpeta `original/` sin problemas.
